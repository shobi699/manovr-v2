## ۱. خلاصه فنی و رویکرد معماری (Technical Summary & Approach)

در سامانه مدیریت مانور مترو، هنگام جمع‌شدن سایدبار ناوبری (`isCollapsed === true`)، دسترسی به عناوین و وضعیت منوها به دلیل حذف متون و وابستگی به ویژگی مرورگری `title` با تاخیر و تجربه کاربری ضعیف همراه است.
همچنین کلاس‌های `.shell.collapsed-sidebar .sidebar { overflow-x: hidden; }` و `.nav { overflow-y: auto; }` موجب بریده شدن هرگونه المان شناور با موقعیت `absolute` داخلی می‌شوند.

**راهکار معماری برگزیده**:
1. **طراحی کامپوننت پرتال شناور سبک `SidebarFlyoutTooltip`**:
   - استفاده از `createPortal` در `document.body` برای فرار قطعی از بریدگی‌های `overflow: hidden` و بافت پشته لایه‌ها (`z-index stacking context`).
   - سنجش دقیق موقعیت المان لنگر با `getBoundingClientRect()` و هماهنگی بلادرنگ با اسکرول و تغییر سایز پنجره.
   - اعمال `pointer-events-none` روی تول‌تیپ جهت جلوگیری از هرگونه تداخل با کلیک کاربر یا لرزش در رویدادهای ماوس.
2. **شتاب‌دهی سخت‌افزاری و انیمیشن روان با `motion/react`**:
   - افکت ترکیبی فید نرم (`opacity: 0 -> 1`)، جابجایی افقی با شیب کم (`x: ±8px -> 0`) و مقیاس ظریف (`scale: 0.95 -> 1`) در مدت زمان زیر ۱۰۰ میلی‌ثانیه.
   - انطباق هوشمند جهت انیمیشن بر اساس وضعیت ناوبری راست/چپ (`navPosition === "left"` یا `"right"`).
3. **طراحی لوکس شیشه‌ای (Glassmorphic) و تایپوگرافی اصولی**:
   - پس‌زمینه نیمه‌شفاف با بلور (`backdrop-blur-md bg-white/95 dark:bg-slate-900/95`).
   - حاشیه و سایه پریمیوم (`border border-slate-200/80 dark:border-slate-800/80 shadow-2xl rounded-xl`).
   - پیکان نشانگر جهت‌نما (Chevron / Arrow indicator) متصل به آیکون متناظر.
   - پشتیبانی از بج‌های موضوعی (دسته‌بندی منو)، نشانگر صفحه فعال (`active`)، وضعیت آکاردئون و رنگ هشدار برای دکمه خروج.
4. **پوشش دسترس‌پذیری (a11y)**:
   - پشتیبانی همزمان از رویدادهای ماوس (`mouseenter / mouseleave`) و فوکوس کیبورد (`focus / blur`) هنگام پیمایش با کلید Tab.

## ۳. بستر و پشته فنی (Technical Context)

- **فریم‌ورک**: Next.js 16 (App Router) + React 19 Client Component
- **کتابخانه انیمیشن**: `motion/react` (نسخه فعال و بهینه شده برای Next.js و React 19)
- **پرتال کلاینت**: `react-dom.createPortal` با کنترل هیدریشن SSR (`mounted === true`)
- **استایل‌دهی**: Tailwind CSS + Glassmorphic CSS Tokens متناسب با تم تاریک/روشن سامانه
- **محیط تست**: Vitest با `@testing-library/react` و `@testing-library/jest-dom`

## ۵. ردیابی پیچیدگی و توجیه تصمیمات (Complexity Tracking)
