## ۳. نتایج ممیزی تخصصی ۵ گانه (Specialized Agent Audits)

### ۱. نتایج آزمون Smoke Tester
- تمام روت‌های اپ بدون مشکل با ساختار استاندارد Next.js App Router بیلد می‌شوند.
- روت‌های ریشه در صورت عدم لاگین، به صفحه `/login` با کد 307 هدایت می‌شوند و از بارگذاری صفحات نیمه‌کاره ممانعت به عمل می‌آید.
- خطاهای ناشناخته سمت کلاینت با Error Boundaryهای مناسب مهار شده‌اند.

### ۲. نتایج آزمون UX & RTL Auditor
- **راست‌چین:** کلیه ساختارهای صفحات اصلی دارای `dir="rtl"` می‌باشند.
- **تایپوگرافی:** فونت Vazirmatn در کل بدنه نرم‌افزار اعمال شده و اعداد در گزارشات و جداول مطابق با فرمت تقویم و زبان فارسی رندر می‌شوند.
- **Micro-interactions:** دکمه‌ها، جدول‌ها و کارت‌ها از استایل شیشه‌ای (Glassmorphism) و حالات ترنزیشن روان پیروی می‌کنند.

### ۳. نتایج آزمون Security Auditor
- **بررسی دسترسی سرور:** Server Actionها (`userActions`, `roleActions`, `manovrActions`) از متد استاندارد `hasPerm(session, permission)` استفاده می‌کنند.
- **امنیت نشست‌ها:** توکن کاربر با استفاده از کتابخانه استاندارد `jose` و با کلیدهای امن امضا و بررسی می‌گردد.
- **ماسک کردن اطلاعات شبکه:** طبق آزمون‌های `offline-sync.test.ts`، آدرس‌های UNC و مسیرهای درایوهای اشتراکی شبکه در لاگ‌ها و پاسخ‌های عمومی فیلتر می‌شوند.

### ۴. نتایج آزمون Adversarial Breaker
- اعتبارسنجی ورودی‌های ایجاد کاربر، تخصیص نقش، طول و ظرفیت خطوط با مدل‌های Zod کنترل می‌شود.
- در برابر ارسال فیلدهای خالی، کاراکترهای مخرب و اعداد منفی، پیام‌های خطای شفاف فارسی به کاربر بازگردانده می‌شود.

### ۵. نتایج آزمون Performance Profiler
- کامپوننت سنگین دپو (`DepotScene.tsx`) به صورت کاملاً ماژولار پیاده شده و به کاربر اجازه می‌دهد بین **نمای دو بعدی برداری فوق‌العاده سریع** و **نمای سه‌بعدی Three.js** سوییچ کند.
- ماژول‌های حجیم مانند PDFMake و ExcelJS تنها در زمان درخواست گزارش بارگذاری می‌شوند تا حجم باندل صفحه اصلی را افزایش ندهند.

## ۵. راهنمای اجرای آزمون‌ها توسط توسعه‌دهنده (How to Run)

۱. **اجرای تست‌های واحد و منطقی (Vitest):**
   ```bash
   npm run test:run
   ```
۲. **اجرای تست‌های سرتاسری (Playwright E2E):**
   ```bash
   npm run test:e2e
   ```
۳. **اجرای تست‌ها با رابط گرافیکی تعاملی (Playwright UI):**
   ```bash
   npm run test:e2e:ui
   ```
