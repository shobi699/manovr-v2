## ۳. بستر و پشته فنی (Technical Context)

- **پشته اصلی**: Next.js App Router (React 19, TypeScript Strict, Tailwind CSS)
- **پایگاه داده و دسترسی**: Prisma ORM (SQLite / PostgreSQL)
- **امنیت و احراز هویت**: Jose JWT + گارد دسترسی `hasPerm(session, permission)`
- **فریم‌ورک آزمون**: Vitest (تست‌های واحد/یکپارچه) + Playwright (آزمون‌های E2E)
- **محیط اجرا**: Web App + Electron Desktop App

## ۴. ساختار فایل‌ها و مسیرهای تغییر (Project Structure)

### مستندات قابلیت (این ویژگی):
```text
specs/[###-feature]/
├── spec.md              # سند مشخصات و سناریوهای کاربری
├── plan.md              # این سند (برنامه فنی)
├── research.md          # یافته‌های فنی و معماری

└── tasks.md             # فهرست تسک‌های شکسته‌شده اجرایی
```

### فایل‌های سورس‌کد پروژه (تغییرات پیش‌بینی‌شده):
```text
src/
├── app/
│   ├── (main)/[feature]/     # کامپوننت‌ها و صفحات فرانت‌اند
│   └── actions/[feature].ts  # اکشن‌های سرور با امنیت hasPerm و اعتبارسنجی Zod
├── components/               # کامپوننت‌های ماژولار و رابط کاربری
├── lib/
│   ├── perms.ts              # به‌روزرسانی کلیدها و گروه‌های دسترسی
│   ├── help-menu-guides.ts   # مستندات راهنمای تفصیلی منو (> ۱۰۰۰ کاراکتر)
│   └── validations/          # اسکیماهای Zod
└── types/                    # تعاریف تایپ‌های داده
e2e/desktop/[feature].spec.ts # تست‌های جامع Playwright
```
